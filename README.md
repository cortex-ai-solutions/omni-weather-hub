# omni-weather-hub
Hyperlokale Wetter-Zeithistorie für Suhl-Goldlauter, Thüringen — ab 2019, stündliche Auflösung. Öffentliches Dark-Mode-Dashboard via GitHub Pages, tägliche Aktualisierung per GitHub Actions (Open-Meteo API), FastAPI-Endpunkt für Ecowitt/Froggit-Hardware &amp; OpenClaw KI-Agenten-Skill.
